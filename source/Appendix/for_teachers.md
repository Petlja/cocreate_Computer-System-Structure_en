# Appendix for Teachers

Here you will find information for teachers.
Tips on how to use markdown are useful to know when formatting documents. More info is available [here](https://www.markdownguide.org/cheat-sheet/).

An expandable component that can be added to pages that students also read is defined like this:

```{learnmorenote} Always visible text

Additional content that is only visible when you click the expand arrow
```

Note: In the GitHub preview, nothing appears expandable. The course must be "compiled" and published to see it (or the tools that create a full preview need to be installed locally, which is not an option for non-developers :)
